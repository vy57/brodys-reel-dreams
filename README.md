# Brody's Reel Dreams

A modern full-stack web application built with **TanStack Start**, **React 19**, and **TypeScript**. This project combines powerful UI components, 3D graphics capabilities, and a complete form-handling ecosystem to create an interactive web experience.

## 🚀 Tech Stack

- **Frontend Framework**: React 19 with TanStack Start
- **Routing**: TanStack Router
- **State Management**: TanStack React Query
- **Language**: TypeScript
- **Styling**: Tailwind CSS with Vite
- **UI Components**: Radix UI (30+ components)
- **3D Graphics**: Three.js with React Three Fiber & Drei
- **Forms**: React Hook Form with Zod validation
- **Animations**: Framer Motion
- **Build Tool**: Vite
- **Code Quality**: ESLint + Prettier

## 📦 Key Dependencies

### UI Components (Radix UI)
- Accordions, dialogs, dropdowns, navigation menus
- Form inputs (checkboxes, radio groups, sliders, switches)
- Data display (progress bars, scroll areas)
- Advanced components (hover cards, context menus, popovers)

### 3D & Graphics
- **Three.js**: 3D graphics library
- **React Three Fiber**: React renderer for Three.js
- **Drei**: Useful helpers for React Three Fiber

### Forms & Validation
- **React Hook Form**: Efficient form state management
- **Zod**: TypeScript-first schema validation
- **@hookform/resolvers**: Integration with Zod validators

### Utilities
- **Framer Motion**: Animation library
- **Embla Carousel**: Carousel component
- **Recharts**: Data visualization
- **Date-fns**: Date utilities
- **Lucide React**: Icon library

## 🛠️ Getting Started

### Prerequisites
- Node.js (latest LTS recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/vy57/brodys-reel-dreams.git
cd brodys-reel-dreams

# Install dependencies
npm install
```

### Development

```bash
# Start development server
npm run dev

# The app will be available at http://localhost:5173
```

### Build

```bash
# Production build
npm run build

# Development build
npm run build:dev

# Preview production build
npm run preview
```

### Code Quality

```bash
# Run linter
npm run lint

# Format code with Prettier
npm run format
```
